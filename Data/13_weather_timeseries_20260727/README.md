# 기상청 D3 시간자료 수집 상태

## 결과

기상청 API허브 `kma_sfctm3.php`의 공식 최대 31일 제한에 맞춰 30일 단위로 분할했으나, 현재 로컬 `KMA_API_KEY`로 모든 요청이 HTTP 403을 반환했다. 인증키는 로그·CSV·XLSX에 기록하지 않았다.

## 산출물 성격

`KMA_wind_timeseries_BLOCKED.xlsx`는 관측 데이터 정본이 아니라 차단 원인·출처·검증·후속 조치를 기록한 보고서다. 관측값이나 대표 사례를 임의 생성하지 않았다.

## 필요한 후속 조치

PM이 기상청 API허브 마이페이지에서 키 유효성과 **지상관측 시간자료(기간 조회)** 활용신청 상태를 확인한 뒤 로컬 `.env`의 `KMA_API_KEY`만 갱신해야 한다. 키를 채팅·문서·`.env.example`에 넣지 않는다.
