# 대피 경로·위험 인자 근거 데이터 정본

## 목적

D1 대피 법규, D2 보행 유동, D4 가스 물성·센서 높이, D6 현장 인원 근거를 QUBO 입력·제약으로 옮길 수 있게 구조화했다.

## 구성

- 법규기준: 국내 법령 강제 조건과 KOSHA 권고를 `force_type`으로 분리
- 보행유동: SFPE/NIST·Weidmann 관계식과 적용 범위
- 가스물성: 상대밀도·분자량과 센서 높이 근거
- 현장인원: 공개 프로젝트 피크 인원 근거
- 합성시나리오: 구역별 공개 실측이 없어 별도 표기한 파생 시나리오
- 데이터사전·출처·품질검사·가정한계

## 사용 원칙

정본은 `QRC2026_evacuation_evidence.xlsx`다. 각 수치는 단위·출처·근거 유형·실제/합성 여부·가정을 함께 사용해야 하며, 합성 인원 배분을 실제 현장 측정치로 표현하면 안 된다.
