## 폴더

1. `00_master/`: Excel에서 바로 사용하는 상세 데이터 정본(XLSX)
2. `01_layout/`: 공개 근거를 바탕으로 만든 **가상 참조 레이아웃**, 12개 센서 후보점, 144행 커버리지 행렬
3. `02_sensor_spec_cost/`: 제조사 사양과 공개 판매가를 분리한 상세 센서 비교표
4. `03_incident_scenarios/`: 공공기관 사고 사례와 명시적 가상 시나리오를 분리한 표
5. `04_legal_criteria/`: 대한민국 현행 법령·행정규칙 핵심 요약
6. `05_ionq_noise/`: IonQ Aria/Forte 공식 공개 성능값

## Excel 사용 기준

- 정본: `00_master/QRC2026_detailed_research_data.xlsx`
- 기존 CSV는 원자료 보존을 위해 덮어쓰지 않았다.
- 파일명이 `_excel_utf8.csv`로 끝나는 10개 보조본은 UTF-8 BOM을 포함하여 Excel 한글 깨짐을 방지한다.
- 정본은 README, 원자료, 정제·파생 데이터, 출처, 데이터사전, 품질검사 시트로 구성한다.
- 2026-07-26 재검사 결과: 엄격한 UTF-8, BOM, 연속 물음표 3개, U+FFFD, 대표 모지바케, 수식 오류, 전 시트 렌더 검사를 모두 통과했다.
