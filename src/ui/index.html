This demo is not connected to live physical sensors. Configure one or more hazard sources by type, location, radius, and intensity to recompute zone-level risk scores. Hazard locations can be placed or moved directly on the floor plan. In a production system, these manual inputs could be replaced by live sensor feeds.

6. Evacuation Inputs

Evacuation exits are user-defined inputs. Add exits by clicking the floor plan in Add Exit mode or by entering coordinates. If no exits are specified, the four grid corners are assumed to be exits and the assumption is reported in the results.
If worker locations are provided, evacuation routes are computed from those locations. Otherwise, routes are evaluated from all zones. The system selects the best exit for each origin and, when worker counts are provided, also estimates congestion delay along evacuation paths.

7. Export

Exported sensor coordinates can be used as candidate locations for the QUBO optimization pipeline.
Demo limitation: wall occlusion and physical obstructions are not modeled; coverage is approximated using circular detection regions.
