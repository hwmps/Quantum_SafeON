4. 재해 시나리오 (예시 설정, 다중 가능)

현재 데모는 실제 감지 센서와 연동되어 있지 않습니다. 아래에서 재해 유형·위치·반경을 예시로 설정하면 그 지점을 기준으로 구역 위험도가 재계산됩니다. 유형이 다른 재해를 여러 건 동시에 추가할 수 있고, 도면을 클릭해 위치를 지정·이동할 수 있습니다. (추후 센서 연동 시 이 목록이 센서 신호로 자동 대체됩니다)

6. 대피 출구 · 작업자 위치 (입력값)

출구는 입력값입니다. 도면 클릭([출구 추가] 모드) 또는 좌표 입력으로 지정하세요. 지정하지 않으면 격자 네 모서리를 출구로 가정합니다(결과에 가정임이 표기됩니다).
작업자 위치를 지정하면 그 지점에서 출발하는 경로만, 지정하지 않으면 모든 구역에서 출발하는 경로를 계산해 구역별 최적 출구를 보여줍니다. 인원을 넣으면 통로 혼잡 지연(초)까지 계산합니다.

7. 내보내기

내보낸 JSON(미터 좌표)은 QUBO 파이프라인의 후보점 입력으로 사용할 예정입니다.
※ 시안 단계: 벽·차폐 미반영, 커버리지는 단순 원형 가정.

8. 최적화 실행 (테스트본)

※ 테스트본: 균일 격자 구역·균일 비용 가정. 실제 파이프라인(위험 점수·법적 제약·실비용)과 다르며 실기 QPU는 호출하지 않습니다. 서버 실행 필요: python src/ui/server.py
